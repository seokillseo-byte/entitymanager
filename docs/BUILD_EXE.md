# Windows `.exe` Build Notes

EntityManager is desktop-first. The normal user should open the tool by clicking a Windows `.exe` installer/app.

## Development Requirements

- Node.js LTS
- pnpm
- Rust stable toolchain
- Windows build tools required by Tauri

## Local Development

```bash
pnpm install
pnpm db:generate
pnpm desktop:dev
```

## Build Windows Installer

```bash
pnpm install
pnpm db:generate
pnpm desktop:build
```

The Windows installer should be generated by Tauri under:

```text
apps/desktop/src-tauri/target/release/bundle/
```

For the NSIS installer target, check this folder after a successful build:

```text
apps/desktop/src-tauri/target/release/bundle/nsis/
```

If the `bundle/nsis` folder does not exist, the build stopped before packaging.
Capture the full log with:

```powershell
pnpm desktop:build 2>&1 | Tee-Object build.log
```

## Packaging Rule

The packaged desktop build must not require normal users to manually start Docker, PostgreSQL, Redis, or a web server. Use local SQLite and local workflow state for V1.
